# CodeAlpha Task 2 – Stock Portfolio Tracker

## Project Description
A Python-based Stock Portfolio Tracker that calculates the total investment value based on predefined stock prices and user-entered quantities.

## Features
- Displays available stock symbols and prices.
- Accepts stock symbols and share quantities.
- Validates stock symbols and quantities.
- Calculates individual stock investment values.
- Calculates total portfolio investment.
- Combines quantities for duplicate stock entries.
- Saves portfolio details in a CSV file.

## Technologies Used
- Python
- Dictionaries
- Functions
- Loops and conditional statements
- Exception handling
- CSV file handling

## How to Run
1. Install Python.
2. Open the project folder in VS Code or Command Prompt.
3. Run:

`python stock_portfolio.py`

## Output
The program displays the portfolio summary and creates a `portfolio.csv` file.
